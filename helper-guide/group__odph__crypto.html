ODPH CRYPTO

API Description

Crypto helper.

The algorithm names used by these functions are the algorithm enumeration names in lower case and without the ODP_CIPHER_ALG_ or ODP_AUTH_ALG_ prefix, e.g. "aes_cbc" for ODP_CIPHER_ALG_AES_CBC and "sha256_hmac" for ODP_AUTH_ALG_SHA256_HMAC.

These functions may be called before ODP initialization.
