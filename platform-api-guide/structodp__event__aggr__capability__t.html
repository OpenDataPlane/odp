union { ... } odp_event_aggr_capability_t::source

Event aggregation support per event source.

Specifies whether events enqueued by a particular event source may be aggregated into event vectors by an event aggregator of this queue type.

A bit set to one indicates a supported event source. When a bit is zero, events from the source are never aggregated. Passing an aggregator queue handle to an unsupported source is still allowed, but has the same effect as passing the handle of the underlying queue (see odp_queue_aggr()). Similarly, unsupported sources which are not passed an aggregator queue handle, but which use an aggregator implicitly based on queue parameters (packet input and classifier), simply enqueue directly to the underlying queue. Queue creation does not fail and the aggregator remains usable by other sources.
